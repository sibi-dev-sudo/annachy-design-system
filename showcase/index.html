Annachy Design System

A browser replica of the Figma design system (file rM3ixSG6i3DFfKZFWuxzs4, the single source of truth): foundations, every component variant, and the pattern screens. It is built with vanilla HTML, CSS and ES modules. The library is src/annachy.css + src/annachy.js; traceability is in docs/replication/.
