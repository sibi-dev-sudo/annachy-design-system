Input Field (Outline & Filled)

OverviewButtonButton (gradient)InputCheckboxRadioToggleDropdownTooltip

All 325 variants. Focused uses .is-focus, Hover .is-hover; Filled has a value; Error uses aria-invalid="true"; Success uses .annachy-input--success; Disabled is native. Fields are shown at the Figma documentation width (337 px). Icon slots are empty (dashed markers). Text uses the temporary fallback font (D-06).

Interactive (hover, focus and type to see native states)

Known Figma characteristics reproduced

  • IN1 / A16 Placeholder #dcdfe5: 1.25:1 on the Filled fill. Filled Hover placeholder #98a0ae: 2.46:1 (IN-13, new).
  • IN2 Outline focus border is raw #3a6ff7; Filled uses Blue/600.
  • IN3 Outline has no Hover state.
  • IN5 Outline always shows the error-circle icon slot.
  • IN-12 Top Section keeps a fixed height (Size + 42).
  • D-09 Radius 6 and 10 are Figma variables without R1 tokens.
