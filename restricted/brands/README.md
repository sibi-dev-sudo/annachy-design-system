# restricted/brands — third-party brand marks (RESTRICTED)

**Rights not verified. Internal reference only. Do not publish, ship or redistribute anything in this folder.**

This folder holds the 624 icon sets of the **Brands** category (Figma page `1801:5142` "② Icons", frame `1802:185706`,
3,930 variants) of the Annachy design-system file. They depict third-party trademarks and logos (for example Adobe,
Google, Zoom). The project owner approved exporting the Icons page for **local, internal design-system replication only**
and asked that this category be kept separate: *"Do not redistribute or publish third-party brand marks without verifying
the applicable rights."* The trademark and licence rights for each brand have **not been verified**.

The folder is deliberately **outside `src/`**, so nothing here is part of the library, its build or its showcase bundle.
Before any brand mark is used in a product or published page, the applicable rights must be verified per brand and
recorded in `manifest.json` (and the icon moved by a reviewed change).

| Path | Content |
|---|---|
| `originals/brands.svg` | Byte-preserved Figma export of the Brands frame (SHA-256 in `manifest.json` and `tests/tools/icons_export/results/exports.json`). Never edited. |
| `svg/outline/<slug>.svg` | Normalised assets (one per set; per-size `<slug>--<size>.svg` where a size is not scale-equivalent). |
| `manifest.json` | Manifest (`status: "restricted"`, `root: "restricted/brands"`), validated by `tests/tools/r7_icons_static.py`. |

Artwork: Iconly-derived (Iconly licence purchased by the project owner; licence text not on file) — internal use only.
Generated by `tests/tools/icons_export/` (see `docs/figma-audit/r7-1-icon-export-report.md`).
